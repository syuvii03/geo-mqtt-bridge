ยังไม่ได้เชื่อมต่อ
ค่าที่กรอกจะถูกจำไว้ในเบราว์เซอร์นี้ (localStorage) ไม่ได้ส่งไปที่ไหน นอกจากไปที่ broker ที่ระบุเอง
ต้องกดยอมรับให้เว็บนี้เข้าถึงตำแหน่ง (GPS) ในเบราว์เซอร์ก่อน • เลือกอุปกรณ์ที่ต้องการรวมในระบบอัตโนมัติได้ที่การ์ดอุปกรณ์ด้านล่าง (เช็คบ็อกซ์ "รวมในระบบอัตโนมัติ") • Geolocation อาจใช้ไม่ได้ถ้าเปิดไฟล์ผ่าน file:// โดยตรงในบางเบราว์เซอร์ ลองรันผ่าน localhost หรือ HTTPS หากอ่านตำแหน่งไม่ได้
ใช้ URL โปรเจกต์ Vercel และ Token (TRIGGER_TOKEN) เดียวกับที่ตั้งไว้ในโปรเจกต์ geo-mqtt-bridge เพื่อให้กราฟย้อนหลัง (รายชั่วโมง/รายวัน/สัดส่วนอุปกรณ์) ซิงค์ข้ามเครื่อง/มือถือ และไม่หายตอนล้าง cache เบราว์เซอร์ • ไม่บันทึก Token ไว้ในเครื่อง ต้องกรอกใหม่ทุกครั้งเพื่อความปลอดภัยขั้นต่ำ (เหมือนรหัสผ่าน broker) • ถ้าไม่กรอก ระบบจะยังเก็บกราฟไว้ในเบราว์เซอร์นี้เครื่องเดียวเหมือนเดิม
