ยังไม่ได้เชื่อมต่อ
ค่าเชื่อมต่อ (Broker Host/Username/Password/Prefix) ถูกฝังไว้ใน DEFAULT_CONFIG ที่ต้นไฟล์แล้ว แก้ไขได้ที่นั่น กดปุ่ม "เชื่อมต่อ" เพื่อเริ่มใช้งาน
⚙️ ตั้งค่ากฎเปิด/ปิดตามระยะ
กำหนดว่าอุปกรณ์ไหนเปิด/ปิดตอนระยะกี่เมตรได้ที่หน้า "ตั้งค่ากฎเปิด/ปิดตามระยะ" (กฎจะแชร์กันระหว่างสองหน้านี้ผ่าน localStorage ของเบราว์เซอร์ ต้องเปิดจากที่เดียวกัน/โดเมนเดียวกัน) • ต้องกดยอมรับให้เว็บนี้เข้าถึงตำแหน่ง (GPS) ในเบราว์เซอร์ก่อน • Geolocation อาจใช้ไม่ได้ถ้าเปิดไฟล์ผ่าน file:// โดยตรงในบางเบราว์เซอร์ ลองรันผ่าน localhost หรือ HTTPS หากอ่านตำแหน่งไม่ได้
ค่า History API URL / Token ถูกฝังไว้ใน DEFAULT_CONFIG ที่ต้นไฟล์แล้ว แก้ไขได้ที่นั่น กดปุ่มนี้เพื่อให้กราฟย้อนหลัง (รายชั่วโมง/รายวัน/สัดส่วนอุปกรณ์) ซิงค์ข้ามเครื่อง/มือถือ • ถ้าไม่กด ระบบจะยังเก็บกราฟไว้ในเบราว์เซอร์นี้เครื่องเดียวเหมือนเดิม
กดปุ่มเรียนรู้ แล้วชี้รีโมทแอร์ตัวจริงมาที่ตัวรับ IR ของบอร์ด (ห่างประมาณ 5-10 ซม.) กดปุ่มที่ต้องการภายใน 30 วินาที บอร์ดจะจำสัญญาณไว้ แล้วสวิตช์ "แอร์" ด้านล่างจะยิงสัญญาณที่เรียนรู้ไปให้แอร์ผ่าน IR LED (ตัวส่ง) • ปุ่มเปิดกับปุ่มปิดของแอร์ส่วนใหญ่ส่งรหัสไม่เหมือนกัน ควรเรียนรู้ทั้งสองปุ่ม
